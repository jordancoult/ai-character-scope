lpfast tuning sheet

Applies to live_test.py and the live bridge (--facefix rel|abs / --facefix-preset). Live commands are typed in the terminal + Enter and take effect from the next frame. /save NAME stores everything marked saved in presets.json; /preset NAME loads it. Defaults below are the current code defaults (2026-11-05).

Ranges: accepted = what the code allows (anything outside is rejected with an error message and nothing changes); useful = where it makes sense in practice. Limit values are in LivePortrait keypoint units, where the whole face is about 1.0 wide.

Expression gains (/gain <region> <value>, --gains, saved)

How strongly your face motion is copied onto the character, per face region. 1 = your motion as is, 0.5 = half, 2 = double, 0 = off (the character keeps his own expression there), negative = mirrored. /gain all 0.8 multiplies every region by 0.8. In abs mode a gain is a blend: 0 = the character's expression, 1 = yours exactly.

Motion limits (/limit <region> <max | knee:max | off>, --limits, saved)

Soft caps so extreme expressions don't tear the face: motion passes unchanged up to the knee, then is compressed towards max and never goes past it. A single value sets max (knee = 2/3 of it). off (or 0) = no limit. Accepted for all: 0 <= knee < max. "Breaks at" = where G-Star's image starts to tear without a limit.

Finding your max with the meters. In live_test the top of the result panel shows a live row for the mouth: lip (mouth opening / lip shape), close (how far your lips press past closed) and jaw (the rest region: cheeks / jaw). Each shows now, pk (the highest value in the last 3 s) and the current max, in exactly the units of /limit (your motion x gain, before limiting), so: make the biggest mouth you want to allow, read pk, and set that (or a little above) as the max. White = below the knee, yellow = being softened, red = at the max (clamped). jaw only moves when the rest gain is above 0 (it's 0 in gstar). /meters off / /meters on hides / shows the row (always starts on, not saved). Live_test only; the bridge has no overlay.

The knee is where squashing starts: about 2/3 of max is a good default. A knee close to max = a hard stop; a low knee = softer, but big expressions look weaker.

Smoothing (/euro [upper|lower] <min_cutoff> <beta> | off, --euro, saved)

A One-Euro filter on your expression before it's applied: it smooths hard while your face is still (removes webcam and low-light jitter, which high gains amplify) and barely at all when you move fast, so lip sync stays quick. It has two independent halves, split at nose level, so you can e.g. calm jittery eyes/brows a lot while keeping the mouth snappy:

HalfWhat it coversKeypoints
uppereverything above the nose: eyebrows, eyelids, forehead, temples0, 1, 2, 8, 9, 10, 11-16
lowereverything below the nose: mouth, lips, cheeks, jaw, chin3-7, 17-20

(Measured on G-Star, the girl reference, your webcam and a portrait clip: the same split on all of them. Two of LivePortrait's "lip" keypoints, 12 and 14, actually sit on the eyes, so they are in upper.)

Drop-out gates (/gate ..., saved)

Saved vs not saved. /save stores mode, pose, gains, all limits, all gates (incl. hold and visibility) and the smoothing (euro, including "off", saved as null). Not saved (start-up flags only): --neutral-ema, --base-ema, --smooth, --source/--crop/--camera/--fps/--layout. Loading a preset first resets limits and gains to the defaults, then applies the preset, so a preset fully reproduces its settings.

Bridge: --facefix-preset NAME and live /preset NAME load the whole preset (limits, gates, smoothing) except pose, which stays off (JoyAI output already moves the head). Bridge equivalents: --facefix rel|abs, --facefix-preset NAME, --facefix-gains 'lip=..,eye=..'; live /gain, /limit, /gate, /euro, /preset.
