AI Character: Start Here

Two terminals: one runs the AI, the other shows you the result.

🔌 Laptop plugged in ⚡ ASUS Performance profile 🌬️ Fan stand on
1

Terminal 1: start the AI character

Option A: StreamDiffusionV2 my settings

Preset 20 (tracks your pose with depth, ~16 FPS), fixed noise, no reference image, plus this prompt:

cd ~/personal/ai-character-scope SCOPE_FUSED_KV=0 PRESET=20 PROMPT="swedish lady with blonde hair, black thin frame glasses" NO_AUDIO=1 ./start_scope.sh --bridge

Wait for [bridge] output ... fps lines. It runs slowly for the first ~30 s while it warms up.

Fixed noise is already the default. Leaving out CHARACTER_REF means no reference image, and depth still works. To use a reference image, put CHARACTER_REF=assets/blonde-gamer-girl.png before ./start_scope.sh.

Option B: LongLive experimental

NVIDIA's LongLive model. It looked more stable and realistic in your test, with about 1.4 s of latency. Pick A or B, not both.

cd ~/personal/ai-character-scope MODEL=longlive PROMPT="swedish lady with blonde hair, black thin frame glasses" NO_AUDIO=1 ./start_scope.sh --bridge

LongLive always uses random noise, because fixed noise builds up artifacts. Depth tracking is off, so presets 20 and 15 run without depth. SCOPE_FUSED_KV=0 isn't needed here, because LongLive turns that patch off by itself. Steps 2–4 below work the same way.

2

Terminal 2: watch the output mirrored

ffplay -fflags nobuffer -flags low_delay -framedrop -probesize 32 -analyzeduration 0 -sync ext -f v4l2 -vf hflip /dev/video10

-vf hflip mirrors only this preview window. OBS and the stream still get the normal, unmirrored feed.

3

Adjust live from the controls page

4

Stop

In terminal 1, press Ctrl+C. Close the ffplay window, or press q.

If it says the port is already in use, an old server is still running. Stop it with:
fuser -k -TERM 8000/tcp
Optional settings (put them before ./start_scope.sh)
PRESET=24Starting FPS preset (30, 24, 20 or 15)
NOISE_MODE=randomStarting noise pattern (fixed, random or auto)
CAMERA=/dev/video0Which webcam to use
MODEL=longliveExperimental LongLive model (random noise only, see README_QUICKSTART.md)
SCOPE_FUSED_KV=0Turns off one speed patch, which you normally run with. About 9% slower, but slightly more realistic. With it on, there's a bit less flicker and invented motion.
NO_AUDIO=1Skips creating the delayed virtual mic

Reference images go in assets/. Frame them the way you sit in front of the camera.
